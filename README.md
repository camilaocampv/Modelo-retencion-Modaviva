# Proyecto de Machine Learning 
## Modelo de clasificación con PYTHON 
Este proyecto es para la empresa textilera, se desarrolla un modelo de clasificación para saber si el cliente comprará o no en los proximos 3 meses.

Se fundaenta en un modelo de regresión logistica.


## Paso a paso para ejecutar el proyecto:
1. ETL modaviva con SQL
2. EDA
3. Modelo de clasificación 
4. Evalaución 
5. Porducción (por medio de API)
6. Desarrollo app streamlit
